Thêm bộ câu hỏi mới

Tải lên tệp JSON theo mẫu bên dưới. Bộ câu hỏi sẽ được lưu trong trình duyệt trên thiết bị này.

ĐỊNH DẠNG TỆP JSON
{
  "title": "Tên bộ câu hỏi",
  "questions": [
    {
      "question": "Nội dung câu hỏi?",
      "options": {
        "A": "Lựa chọn A",
        "B": "Lựa chọn B",
        "C": "Lựa chọn C",
        "D": "Lựa chọn D"
      },
      "answer": "B",
      "explanation": "Giải thích (không bắt buộc)"
    }
  ]
}

Mỗi câu cần có câu hỏi, các lựa chọn và đáp án đúng (A, B, C...).
